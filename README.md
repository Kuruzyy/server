# NixOS Homelab Configuration

This is my NixOS configuration for a homelab server, managed as a flake.

## Quick Start

```bash
# From WSL or Linux:
nix build .#lilith-server
# Or deploy:
nixos-anywhere --flake .#lilith-server <hostname-or-ip>
```

## Requirements

- NixOS unstable (or pin to specific release)
- A machine with Nix installed (WSL recommended on Windows)
- ~128GB NVMe for disk layout (see disk-config.nix)
- Incus for container virtualization

## Directory Structure

```
.
├─ flake.nix          # Flake entrypoint
├─ host/
│  ├─ server/
│  │  ├─ disk-config.nix   # Disk partitioning (disko)
│  │  └─ lilith-server.nix # Full host configuration
│  └─ home/           # (empty currently - home-manager not wired)
├─ facter.json        # Generated by nixos-anywhere at install
└─ configuration.nix # (not used - flake-based)
```

## Security Considerations (for GitHub upload)

**Do NOT commit any of the following:**
- Private SSH keys (already `authorizedKeys.keys = []`)
- Passwords or secrets (none stored in config)
- Machine-specific credentials

**Important hardening notes:**

1. **Password file** - A hashed password is set via `hashedPasswordFile = "/persist/etc/password-lilith"` in the NixOS config. The hash file is injected at deploy time using `nixos-anywhere --extra-files`. See the "Bootstrap" section below for the exact procedure. The console password can be changed only by rebuilding the flake (since `mutableUsers = false`).

2. **SSH** - `PasswordAuthentication = false` and `authorizedKeys.keys = []` (empty). Add your public key to `services.openssh.authorizedKeys.keys` to enable SSH key login. Keys may be added now or after first console login. The default port is `1444`.

## Customization

- Edit `host/server/lilith-server.nix` for host-specific settings
- Generate `facter.json` via `nixos-anywhere --flake .#lilith-server --generate-hardware-config ./facter.json <host>`
- Add home-manager config under `host/server/home/` if desired
- Adjust disk sizes, IPs, and package lists as needed
